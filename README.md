# 小火车识字探险

面向 4 岁左右儿童的纯前端识字闯关游戏。无需账号和后端，学习记录只保存在浏览器本机，也可以通过纯文本复制、下载和恢复。

## 已实现

- 8 个内置关卡，每关 4 个常用汉字
- 逐字认读、中文语音朗读、听音选字、装字上车
- 家长可跳过路线锁定，手动选择任意关卡
- 本地保存关卡、星级、错误次数和累计练习数
- 纯文本学习记录导入、复制和 `.txt` 下载
- “暖暖绘本小火车”与原创“勇气救援小狗队”两套主题
- 适配桌面和手机，支持键盘焦点与减少动态效果偏好

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

仓库包含 GitHub Pages 部署工作流。私有仓库需要支持 Pages 的 GitHub 套餐；也可以在确认后把仓库设为公开，再手动运行 `Deploy to GitHub Pages`。

## 用脚本切换默认主题

主题包只改变颜色、载具、角色称呼和界面文案，不修改关卡与学习记录。

```bash
npm run theme -- train
npm run theme -- rescue
```

脚本会更新 `src/themes/active-theme.json`。用户在家长中心做的运行时选择保存在浏览器中，并优先于构建默认值。

## 学习记录格式

导出的内容是方便阅读和粘贴的纯文本：

```text
小火车识字游戏学习记录
格式版本=1
当前关卡=home
已解锁=home,nature
累计识字=4
完成记录:
home|3|0|2026-08-01T00:00:00.000Z
```
